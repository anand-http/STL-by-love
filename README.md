# STL by Love

C++ examples demonstrating Standard Template Library containers and algorithms.

## Contents

- `1_algorithm.cpp` — common algorithms
- `3_array.cpp` — array examples
- `4_deque.cpp` — deque examples
- `5_list.cpp` — list examples
- `5_map.cpp` — map examples
- `6_priorityqueue.cpp` — priority queue examples
- `7_queue.cpp` — queue examples
- `8_set.cpp` — set examples
- `9_stack.cpp` — stack examples

## Run

Compile an example with a C++ compiler, for example:

```bash
g++ -std=c++17 3_array.cpp -o example
./example
```
